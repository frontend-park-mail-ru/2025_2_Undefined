# @undefined/lib

Небольшая локальная библиотека React с компонентом Button.

Сборка:

```bash
cd lib
npm install
npm run build
```

Использование в основном проекте (локально):

1. В корне проекта выполните `npm install ./lib` — это добавит пакет в node_modules как локальную зависимость.
2. Импортируйте компонент: `import { Button } from '@undefined/lib'`.
